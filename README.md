**Name:** Bola Melad Wasfy Selim

**Student ID:** 2300290

## Description
A Java project that implements a UML class diagram for an employee management system.
It includes an abstract `Employee` class with three subclasses (`HourlyEmployee`,
`MonthlyEmployee`, `CommissionEmployee`), a `Department` class that manages employees
and calculates total payroll, and a `Gender` enum.

## Project Structure
- `src/model` : Employee, HourlyEmployee, MonthlyEmployee, CommissionEmployee, Department, Gender
- `src/test/MainTest.java` : demo with sample data
- `src/Main.java` : entry point that runs MainTest

## How to Run
1. Clone the repository:
   `git clone https://github.com/Bola-2005/java-diagram-project-bola.git`
2. Open the project in IntelliJ IDEA (or any Java IDE) with JDK 17 or newer.
3. Run the `main` method in `src/test/MainTest.java` (or `src/Main.java`).
